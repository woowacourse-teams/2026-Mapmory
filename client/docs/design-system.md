# Mapmory 디자인 시스템

공통 UI는 Android와 iOS가 같은 의미 토큰과 컴포넌트 스타일을 사용합니다. 새 화면과 기존 화면을 고칠 때 화면별 색을 직접 지정하기보다 의미 토큰을 먼저 사용합니다.

## 레이어

1. **색상 원시값**: `TripRecordColors.kt`의 팔레트별 색상값입니다.
2. **의미 토큰**: `TripRecordColors`, `TripMapColors`, `TripStatisticsColors`가 배경, 본문, 강조, 지도 영역, 통계 지도의 역할을 정의합니다.
3. **컴포넌트와 화면**: 화면은 `TripRecordPalette`, `TripMapPalette`, `TripStatisticsPalette` 또는 `MaterialTheme`에서 값을 가져옵니다.

글자는 `MapmoryTypography()`의 Line Seed KR 글꼴을 사용합니다. 공통 Material 3 모서리는 8, 14, 18, 20dp 단계로 맞춥니다. 여백은 4dp 단위로 조합하고, 새 화면은 8, 12, 16, 20, 24, 32dp를 우선 사용합니다.

## 테마 선택

화면 밝기와 색상 계열은 서로 독립적으로 선택합니다.

| 설정 | 선택지 | 저장 위치 |
| --- | --- | --- |
| 화면 테마 | 라이트, 다크 | 기존 설정 키 유지 |
| 색상 테마 | 맵모리 그린, 오션 블루 | Android `theme_palette`, iOS `mapmory_theme_palette` |

저장값이 없거나 알 수 없으면 기존 사용자 화면을 보존하도록 맵모리 그린을 사용합니다. 선택은 앱을 다시 열어도 유지됩니다.

## 팔레트 방향

| 계열 | 라이트 | 다크 | 강조색 |
| --- | --- | --- | --- |
| 맵모리 그린 | 따뜻한 흰 배경, 옅은 녹색 표면 | 짙은 차콜 배경, 어두운 녹색 표면 | `#4D9272`, `#35C987` |
| 오션 블루 | 기존 흰 배경 유지, 옅은 청색 표면과 경계 | 기존 차콜 배경 유지, 네이비 표면 | `#246DBB`, `#6EA9F3` |

오션 블루는 참고 시안의 차분한 네이비와 파란 지도 강조를 반영합니다. 라이트·다크 모두 기존 페이지 바탕색은 유지해 iOS 안전 영역과 화면 배경이 어긋나지 않게 합니다. 세계 지도, 대한민국 지도, 통계 지도도 같은 팔레트를 사용합니다.

## 적용 규칙

- 일반 화면에서는 의미가 맞는 팔레트 토큰을 사용합니다. 새 화면에 원시 색상을 직접 넣지 않습니다.
- Material 3 컴포넌트는 `MaterialTheme.colorScheme`, `typography`, `shapes`를 우선 사용합니다.
- 여행 공유용 포스터와 업적 배지는 각각의 시각 디자인을 유지하는 결과물입니다. 앱의 색상 테마를 바꿔도 해당 아트워크 자체의 색상은 바꾸지 않습니다.
- 색상 조합을 추가할 때 작은 글자 대비도 확인합니다. 오션 블루 라이트의 주요 본문색은 흰 배경에서 WCAG AA 일반 텍스트 기준을 넘도록 선택했습니다.
