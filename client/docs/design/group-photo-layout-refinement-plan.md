# 그룹·사진 상세 배치 및 제스처 개선 계획

- 작성일: 2026-11-05
- 상태: 계획 작성 / 이번 요청의 기능 구현 전
- 브랜치: `and/feat/login-ui-polish`
- 이전 작업을 보존한다. 이번 요청은 계획서 작성이며 코드 변경을 포함하지 않는다.

## 1. 일지 영상 카드 배경 수정

이전 변경에서 카드 배경을 `surface`로 바꾸면서 라이트 테마에서는 흰색이 되었다. 사용자의 의도는 흰색 통일이 아니라 카드 안에서 배경색이 따로 보이지 않게 하는 것이다.

- 영상 카드의 기존 테마 강조 배경 `primarySoft`를 복원한다.
- 원형 진행 표시를 감싼 40dp 영역의 독립적인 `surface` 배경을 제거해 카드 배경이 그대로 보이게 한다.
- 2개국 이상이면 진행 원과 보조 문구를 숨기는 현재 요구사항은 유지한다.
- 0/2·1/2·조회 중 상태에서 흰 사각형이 나타나지 않는지 확인한다. 그린/블루, 라이트/다크 모두 테마 색을 따른다.

대상: `TripRecordListScreen.kt`의 `TripTimelineVideoEntry`.

## 2. ‘내 그룹’ 제목 기준선 통일

‘여행 통계’, ‘설정’, ‘나의 여행’은 좌우 20dp·헤더 세로 18dp에 영문 라벨과 그 아래 4dp 간격의 25sp 제목을 배치한다. 현재 ‘내 그룹’에는 영문 라벨이 없어 여백 수치만 같아도 제목이 더 위에 놓인다.

- 다른 탭과 같은 헤더 구조를 적용한다. 상단에 `MY GROUPS` 라벨을 두고 아래에 ‘내 그룹’을 배치한다.
- 라벨의 서체·10sp 크기·자간·색상과 제목의 25sp·Bold·4dp 간격을 기존 탭 기준에 맞춘다.
- 안전 영역을 포함한 실제 화면 좌표에서 제목의 왼쪽 시작점과 글자 기준선을 비교한다.
- 제목 아래 버튼 간격은 별도로 유지한다. 기존 탭 제목 위치를 이동해서 그룹에 맞추지 않는다.
- 큰 글씨에서도 고정 높이로 잘리지 않도록 내용 기반 높이를 사용한다.

대상: `GroupScreens.kt`의 `GroupListScreen`. 기준 확인: `TripProfileScreen.kt`, `TripSettingsScreen.kt`, `TripRecordListScreen.kt`.

## 3. 겹친 사각형 복사 아이콘의 가림 처리

현재 두 사각형을 선으로 각각 그려 겹친 영역에서 뒤쪽 사각형 선이 앞쪽 내부를 통과한다.

- 뒤 사각형 → 앞 사각형 내부 가림 → 앞 사각형 외곽선 순서로 그린다. 가림 색은 실제 시트 표면색을 사용한다.
- 또는 앞 사각형 영역을 제외하도록 뒤 사각형 경로를 잘라서 그린다. 라이트/다크 모두 뒤쪽 선이 비치지 않는 구현을 선택한다.
- 기존 위치와 48dp 터치 영역, ‘초대 코드 복사’ 접근성 이름 및 코드 영역 터치 복사를 유지한다.
- Android 시스템 복사 안내와 앱 안내가 중복되지 않도록 한 기존 정책을 유지한다.

대상: `LiveGroupContent.kt`의 초대 코드 복사 아이콘.

## 4. 그룹 사진 상세 확대와 제스처 충돌 방지

현재 `GroupPhotoScreen`은 `HorizontalPager`에 일반 이미지만 표시한다. 개인 기록 사진 상세에는 1~4배 확대, 팬 이동, 더블 탭 확대가 구현되어 있다. 해당 동작을 기준으로 그룹 사진에도 적용하되, 확대와 페이지 전환의 입력 소유권을 명확히 한다.

| 상태 | 허용 동작 |
| --- | --- |
| 1배·한 손가락 | 좌우 사진 전환, 기존 아래로 닫기 |
| 두 손가락 접촉/핀치 진행 | 확대·축소·이미지 이동, 페이지 전환과 아래로 닫기 차단 |
| 1배 초과 | 이미지 내부 팬 이동, 페이지 전환과 아래로 닫기 차단 |
| 핀치 후 한 손가락만 남음 | 모든 손가락을 뗄 때까지 페이지 전환 차단 |
| 모든 손가락 해제 후 1배 | 다음 제스처부터 사진 전환·아래로 닫기 재허용 |

- 확대 배율은 1~4배, 1배 복귀 시 이동량은 0으로 초기화한다. 이미지가 화면 밖으로 사라지지 않도록 팬 범위를 제한한다.
- 개인 사진 상세와 동일하게 더블 탭으로 확대/원상 복귀한다.
- 배율만 검사하지 않고 두 손가락 접촉 시작부터 입력을 소비한다. 축소가 1배에 도달한 순간 남은 손가락이 옆 사진을 넘기지 않게 한다.
- 페이지별 상태는 사진 ID를 키로 관리한다. 다른 사진으로 이동하면 새 사진은 기본 배율로 표시한다.
- `MapmoryPhotoViewer.canDragDown`과 pager의 `userScrollEnabled`를 동일한 제스처 상태에 연결한다.
- 필요하면 개인 사진 상세의 확대 처리를 공통 컴포넌트로 추출한다. 공통화 시 개인 사진 확대/뒤로가기에도 회귀 검증을 수행한다.

대상: `GroupScreens.kt`의 `GroupPhotoScreen`, 필요 시 `presentation/components`의 확대 이미지 컴포넌트. 참고: `TripRecordDetailScreen.kt`, `MapmoryPhotoViewer.kt`.

## 5. 사진 업로더 문구를 왼쪽 아래로 이동

현재 공통 뷰어는 하단에 16dp 여백을 주고, 그룹 문구가 추가로 24dp 여백과 중앙 정렬을 사용해 안쪽으로 많이 들어가 있다.

- ‘○○님이 올린 사진’ 영역을 가로 전체 너비의 시작 정렬로 바꾼다.
- 그룹 화면의 추가 24dp 패딩을 제거하고, 공통 뷰어의 안전 영역과 기본 16dp 여백을 기준으로 왼쪽 아래에 배치한다.
- 길이가 긴 닉네임은 줄바꿈/말줄임으로 처리하고, 시스템 제스처 영역에 겹치지 않게 한다.
- 사진 삭제 액션이 표시되는 경우 업로더 문구와 분리해 배치한다. 확대/팬 동작을 불필요하게 가로채는 큰 투명 터치 영역을 만들지 않는다.

## 6. 앨범 ‘+’ 버튼을 지도와 같은 위치에 배치

지도는 `TripRecordCreateButton`을 사용하며 바깥 여백은 오른쪽 28dp·아래 33dp, 크기는 48dp이다. 앨범은 같은 여백 숫자를 사용하더라도 다른 `TripIconButton`과 다른 부모 레이아웃을 사용하므로 화면상의 위치가 일치한다고 볼 수 없다.

- **지도 화면과 지도 + 버튼 구현은 변경하지 않는다.**
- 지도 버튼의 실제 원 크기, 터치 영역, 중심 좌표, 하단 바와의 거리를 기준으로 앨범 버튼만 맞춘다.
- 앨범 버튼을 하단 탭바 위의 고정 콘텐츠 영역에 배치한다. 로딩/오류/진행 안내 등의 높이에 따라 버튼이 밀리지 않게 한다.
- 지도 버튼과 시각적으로 같은 48dp 원형 버튼을 사용하되, 액션은 ‘이 앨범에 사진 추가’를 유지한다. 지도용 분석 이벤트를 잘못 발생시키지 않는다.
- 화면 크기·안전 영역·Android 제스처/3버튼 내비게이션에 따라 동일 좌표가 유지되는지 스크린샷을 겹쳐 확인한다.

대상: `GroupScreens.kt`의 `GroupAlbumScreen`, 필요 시 `LiveAlbumContent.kt`의 버튼 호스트. 기준 읽기: `TripMapScreen.kt`, `TripRecordComponents.kt`.

## 7. 앨범별 스크롤 상태 보존

현재 `GroupAlbumScreen` 내부에 `rememberLazyListState()`가 있지만, `LiveAlbumContent`의 조건 분기에서 사진 상세로 이동하면 앨범 화면이 구성에서 제거된다. 그 결과 화면 내부 상태만으로는 돌아왔을 때 위치 보존을 보장할 수 없다.

- 그룹 ID + 앨범 ID를 키로 상태를 보존하는 상위 `SaveableStateHolder`를 두거나, 앨범별 스크롤 상태를 상위로 끌어올린다.
- 목록의 첫 표시 항목과 오프셋, 사진 열 수를 함께 보존한다. 사진 상세·기록 선택·모달에서 돌아오거나 같은 앨범을 다시 열면 이전 위치를 복원한다.
- 그룹의 앨범 목록 자체 위치도 별도 키로 보존해 앨범 상세에서 뒤로 갔을 때 목록 시작으로 튀지 않게 한다.
- 사진 추가/삭제·정렬 변경 시 항목 ID를 기준으로 복원하고, 기존 항목이 사라졌다면 가장 가까운 유효 위치로 보정한다.
- 다른 앨범의 위치가 섞이지 않게 하고 계정 변경·그룹 탈퇴·앨범 삭제 시 해당 상태를 정리한다. 영구 저장은 범위에 포함하지 않으며 화면 전환과 일반적인 화면 재생성에서의 복원을 목표로 한다.

대상: `LiveGroupContent.kt`, `LiveAlbumContent.kt`, `GroupScreens.kt`, 필요 시 `AlbumNavigationState.kt`.

## 구현 순서 및 완료 기준

1. 배경·헤더·복사 아이콘·업로더 문구를 수정한다.
2. 지도 화면을 기준으로 앨범 + 버튼의 좌표와 크기를 맞춘다.
3. 앨범별 상태 보존을 구현하고 사진 상세 확대와 제스처 우선순위를 연결한다.
4. JVM 상태 테스트, Android 빌드, iOS 공통 코드 컴파일을 수행한다.
5. 실제 기기 또는 에뮬레이터에서 핀치 중 가로 이동/한 손가락 해제/축소 후 전환, 확대 상태의 닫기 방지, 사진 간 전환을 검증한다.
6. 앨범 중간 위치 → 사진 상세 → 뒤로가기, 다른 앨범 왕복, 새 사진 추가 후 복귀, 화면 재생성에서 위치 보존을 확인한다.
7. 테마 4조합과 큰 글씨에서 배경·제목·아이콘을 확인하고, 지도/앨범 버튼 및 탭 제목의 화면 좌표를 비교한다.

빌드 통과와 실제 제스처·배치 확인은 별도로 기록한다. 앞선 요청에서 남은 그룹 새로고침 보완 및 영상 생성 제한 연결은 이 계획과 별도 미완료 항목이다.
