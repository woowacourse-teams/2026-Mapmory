# 에브리타임 서비스 홍보글

> 작업용 초안입니다. 게시 전에 대괄호로 표시한 항목을 실제 값으로 바꿉니다.

## 제목

여행 사진과 기억을 지도에 남기는 앱, Mapmory를 소개합니다

## 본문

안녕하세요. 여행한 장소와 그때의 기억을 지도에 남기는 앱 **Mapmory**를 만들고 있습니다.

여행 사진은 갤러리에 남아 있지만, 시간이 지나면 어디서 찍었는지 다시 찾기 어려울 때가 있잖아요. Mapmory는 여행한 지역을 지도에서 확인하고, 장소별로 사진과 기록을 정리할 수 있는 서비스입니다.

Mapmory에서는 다음 기능을 이용할 수 있습니다.

- 지도에서 방문한 지역 확인
- 장소를 선택해 여행 기록 작성
- 해당 장소에서 촬영한 사진 추천
- 저장한 기록을 일지에서 다시 확인

### 이용 방법

1. 아래 Play 스토어 링크로 앱 설치
2. 지도에서 방문 지역 확인
3. 여행 기록 작성
4. 사진을 첨부하고 저장
5. 저장한 기록 다시 확인

처음 기록을 남기는 데 약 **[5분]** 정도 걸립니다.

### 이런 분께 추천합니다

- 여행 사진은 많지만 장소별로 정리하기 어려운 분
- 다녀온 지역을 지도에서 한눈에 보고 싶은 분
- 여행의 순간을 사진과 글로 남기고 싶은 분

사용해보신 뒤 불편한 점이나 추가되었으면 하는 기능이 있다면 서비스 개선에 참고하겠습니다.

다운로드: https://play.google.com/store/apps/details?id=com.mapmory.android

위 링크에서 앱을 설치한 뒤 바로 사용해보실 수 있습니다.

서비스 소개: https://map-mory.com/

※ 일부 기능은 계속 개선하고 있습니다.
