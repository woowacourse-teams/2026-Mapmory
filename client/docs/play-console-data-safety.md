# Mapmory Play Console 데이터 보안 응답표

기준: 서버 연동과 사진 업로드가 연결된 출시 AAB에서 실제로 실행되는 기능.

## 현재 구현 확인

- 앱은 게스트 인증 후 여행 기록을 API 서버에 저장하고 조회합니다.
- 여행 제목·내용·날짜·선택 지역·태그와 게스트 회원 식별 정보가 서버로 전송됩니다.
- 이용자가 첨부한 사진 원본은 Presigned URL을 통해 S3로 직접 업로드됩니다.
- 사진 원본에 EXIF 위치·촬영 시각 등이 남아 있으면 함께 전송될 수 있습니다.
- 장소 기반 사진 추천을 위해 기기 사진과 EXIF 위치정보에 접근합니다. 추천용 사진 메타데이터는
  기기 안에서 처리하지만, 이용자가 기록에 첨부한 사진 원본은 기기 밖으로 전송됩니다.
- Android 앱은 프로젝트별 `google-services.json`과 Firebase Analytics SDK가 포함된 빌드에서 화면 진입·기능 사용 이벤트를 수집합니다.
  iOS도 별도 Firebase 설정 파일과 SDK를 통해 같은 이벤트를 수집합니다. 최종 배포 빌드에서 실제 활성화 여부를 확인한 뒤 데이터 보안 응답을 확정해야 합니다.
- 서버 오류 로그에는 요청 ID, 요청 방식·경로·응답 상태와 오류 코드가 기록되며 7일간 보관됩니다.

## Play Console 응답

| 질문 | 응답 |
| --- | --- |
| 앱이 필수 사용자 데이터 유형을 수집하거나 공유하나요? | 예, 사용자 데이터를 수집함 |
| 광고를 포함하나요? | 아니오 |
| 로그인 또는 리뷰어 계정이 필요한가요? | 아니오 |
| 데이터 공유 | 현재 앱 기능 기준 제3자에게 판매·공유하지 않음. Play의 서비스 제공업체 예외 요건은 제출 전 재확인 |
| 사용자 ID | 게스트 회원 식별 및 인증, 앱 기능 제공 |
| 사용자 생성 콘텐츠 | 여행 제목·내용·날짜·지역·태그의 저장과 동기화 |
| 사진 | 이용자가 선택한 여행 사진의 저장과 조회 |
| 위치 | 선택 지역과 사진 원본에 포함될 수 있는 EXIF 위치정보. 실제 제출 항목은 최종 AAB와 네트워크 검증 후 확정 |
| 앱 정보 및 성능 | 오류 분석에 필요한 요청·응답 상태와 오류 코드 |

사진 추천용 메타데이터처럼 기기 안에서만 처리되는 정보와 서버로 전송되는 정보를 구분해야 합니다.
여행 기록과 첨부 사진은 기기 밖으로 전송되므로 데이터 보안 양식의 수집 대상입니다.

## 배포 직전 재확인

- [ ] 실제 제출 AAB가 이 문서의 기준 커밋에서 빌드되었는가
- [ ] 게스트 인증, 여행 기록 API와 사진 업로드가 실제 제출 빌드에서 동작하는가
- [ ] 네트워크 프록시로 여행 기록과 사진의 실제 전송 항목을 확인했는가
- [ ] 사진 원본의 EXIF 위치정보가 제거되지 않고 전송되는지 확인했는가
- [ ] Firebase Analytics가 최종 AAB에서 활성화되어 있는지 확인했는가
- [ ] Firebase Analytics가 활성화되어 있다면 앱 활동·기기 또는 기타 ID 수집과 목적을 Play Console에 신고했는가
- [ ] 데이터가 전송 중 암호화되는가
- [ ] 앱 내 기록 삭제와 이메일 삭제 요청 절차를 Play Console에 정확히 설명했는가
- [ ] 데이터 보안 응답과 개인정보처리방침의 항목·목적·보유기간이 일치하는가
