# 그룹 나가기·삭제 결과의 앱 반영

## 기준

사용자 결정: 앱은 서버 계약을 따른다. 데이터 파기나 그룹 삭제 규칙을 앱에서 재구현하지 않는다.

- [#540](https://github.com/woowacourse-teams/2026-Mapmory/pull/540): `DELETE /api/v1/groups/{groupId}/members/me`, 성공은 본문 없는 `204`.
- [#539](https://github.com/woowacourse-teams/2026-Mapmory/pull/539): 원본 여행 기록을 삭제하면 서버가 모든 앨범의 해당 항목을 정리하고 빈 앨범을 삭제한다.
- 계약 확인 기준: `origin/backend-develop`의 `GroupController`, `GroupLeaveService`, `GroupErrorCode`, `AlbumQueryService`. `api.md` 상단 구현 상태 표에는 과거 상태가 남아 있어 구현 코드와 PR을 함께 확인했다.

## 앱 동작

- 그룹 홈 메뉴에서 나가기 확인 화면을 연다. 내 개인 기록은 남고, 이 그룹에서 공유한 기록·사진은 내려간다고 안내한다. 마지막 멤버의 나가기와 빈 앨범 정리는 서버 책임이다.
- `204` 또는 `404 GROUP_NOT_FOUND`로 더 이상 참여 중이 아님을 확인한 후 그룹 화면과 초대 상태를 정리한다. 다른 종류의 `404`를 성공으로 취급하지 않는다.
- 네트워크 오류·시간 초과·5xx는 결과 미확인이다. 자동으로 DELETE를 재전송하지 않고 `GET /groups/{groupId}`로 참여 상태를 확인한다. 여전히 멤버라는 응답을 받은 뒤에만 사용자가 다시 나갈 수 있다.
- 나가기는 앱 수명의 작업으로 실행한다. 화면 종료로 요청을 취소하지 않는다. 요청 중에는 공유·계정 전환이 서로 겹치지 않도록 차단한다.
- 나간 그룹의 완료·실패·결과 미확인 공유 작업은 정리하고, 이전에 큐에 들어간 공유가 뒤늦게 실행되지 않게 무효화한다. 다른 그룹의 작업은 유지한다.
- 프로세스 재시작 후에는 그룹 목록을 서버에서 다시 읽는다. 나가기 요청은 자동 재실행하지 않는다.
- 개인 기록 수정·삭제 알림을 받으면 그룹 목록과 앨범 목록·현재 상세를 다시 읽는다. `ALBUM_NOT_FOUND`이면 사진·선택·편집 화면을 닫고 목록으로 돌아간다. `GROUP_NOT_FOUND`이면 그룹 목록으로 돌아간다. 일시적인 조회 실패는 기존 화면을 유지한다.
- 사진 URL이 갱신되면 사진 ID를 기준으로 현재 사진을 유지한다. 해당 사진이 없어졌으면 전체 화면 보기를 닫는다.
- 다른 기기의 변경은 화면 재진입·수동 새로고침으로 확인한다. 실시간 푸시 동기화는 이 변경에 포함하지 않는다.

## #435와 탈퇴 계약의 범위

[#435의 2026-10-29 결정](https://github.com/woowacourse-teams/2026-Mapmory/issues/435#issuecomment-6487479398)은 탈퇴·버려진 게스트 데이터를 30일 뒤 일일 배치로 파기하고, 의견은 익명화한다는 서버 정책이다. 앱용 파기 API가 새로 생긴 것은 아니다.

확인 당시 #435의 파기 배치, #549 처리방침 변경은 미완료이며, #551 푸시 토큰 정리·#552 탈퇴 후 전체 그룹 나가기·#554 Apple 재인증/토큰 철회도 미병합이다. 따라서 앱에서 30일 파기 완료나 탈퇴 직후 전체 그룹 정리를 보장하지 않고, 사용자 대신 그룹별 DELETE를 호출해 탈퇴를 흉내 내지도 않는다.

이 변경은 회원 탈퇴 UI나 Apple 탈퇴 연동을 추가하지 않는다. 계정 로그아웃·게스트 재발급 흐름은 기존 계약을 유지한다. 위 PR들의 병합·배포와 앱 탈퇴 연동은 별도로 확인해야 한다.

## 검증

- 저장된 계정의 실제 그룹을 나가거나 기록을 삭제하지 않고 MockEngine·상태 테스트·Compose 화면 테스트로 확인한다.
- 빈 `204`, 만료 토큰 갱신, 정책 오류, 중복 확인, 응답 유실 뒤 조회, 잘못된 404, 화면 이동, 계정 변경 후 늦은 응답, 그룹별 공유 작업 정리를 검증한다.
- 기록 변경 알림에 따라 실제 Compose 화면이 상세를 재조회하고 삭제된 앨범에서 빠져나오는지 검증한다.
- Android 빌드와 iOS 시뮬레이터용 공통 코드 컴파일은 실서버 배포·실기기 삭제 검증과 구분한다.
