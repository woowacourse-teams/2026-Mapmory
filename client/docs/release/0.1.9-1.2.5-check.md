# 2026-10-28 배포 준비 점검

기준: #487이 머지된 `develop@4aefa110`을 병합한 상태. 작업 브랜치: `codex/release-detail-skeleton`.

## 변경

- Android: `0.1.8 (11)` → `0.1.9 (12)`.
- iOS Debug/Release/Internal: `1.2.4 (6)` → `1.2.5 (7)`.
- 일지 상세 로딩에 목록의 앨범/타임라인 선택을 전달한다. 앨범형은 대표 사진, 갤러리 제목, 날짜, 사각 사진 격자를 표시하고 실제 화면과 대표 사진 높이·사진 크기 계산을 공유한다. 타임라인형은 제목, 시간순 기록, 연도 필터, 64 dp 사진 줄을 표시한다.
- 아직 응답하지 않은 메모·날짜별 사진 분포·제목 길이는 알 수 없으므로 로딩 화면과 완료 화면의 모든 높이가 같다고 보장하지 않는다.
