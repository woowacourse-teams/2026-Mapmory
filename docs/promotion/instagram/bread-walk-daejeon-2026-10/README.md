# 대전 빵축제 Instagram 캐러셀

최종 점검: 2026-10-16
형식: Instagram 4:5 캐러셀, 4장
발행 적기: 2026년 10월 16–18일
목표: 축제 방문을 계기로 Mapmory의 장소·사진 기반 여행 기록을 소개하고 첫 기록으로 연결

## 캐러셀 흐름

1. **후킹:** “그 빵, 어디서 먹었지?”라는 장소 기억 문제로 시선을 끕니다.
2. **쓸모:** 이번 주말 행사 일정, 장소, 현장 안내를 한 장에서 확인합니다.
3. **제품 가치:** 장소 선택 → 사진 선택 → 여행 기록 저장 흐름을 보여줍니다.
4. **행동:** 앱에서 첫 빵 여행 기록을 남기도록 안내합니다.

## 캡션 초안

대전 빵축제 가시나요? 🍞
올해는 대전 빵집 120곳이 엑스포과학공원에 모인대요. 브레드 갤러리에서 참여 빵집과 대표 메뉴를 살펴보고, 대전 빵 지도에서 위치도 확인해 보세요.

맛있었던 빵은 사진으로, 어디서 먹었는지는 장소와 함께 Mapmory 여행 기록으로 남겨보세요. 나중에 기록을 다시 열면 그날의 빵과 장소를 함께 떠올릴 수 있어요.
