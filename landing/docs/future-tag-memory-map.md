# 태그 기반 기억 지도 후속 아이디어

- 상태: 아이디어 백로그 · 미구현
- 전제: 실제 Mapmory 앱에 태그 기능이 추가된 이후에만 검토

## 배경

랜딩의 대한민국 대표 사진이 라멘일 때 Mapmory 전체가 라멘 지도 서비스처럼
보인다는 피드백이 있었다. 메인 랜딩은 여행과 장소 기억이라는 제품 정체성을
먼저 전달하고, 음식 사진은 여러 장소 기억 중 하나로만 보여준다.

## 후속 방향

태그 기능이 실제 제품에 추가되면 사용자가 같은 태그의 기억만 모아 주제별 지도를
볼 수 있는 흐름을 검토한다. 예를 들어 `라멘` 태그를 선택하면 여러 지역에서 남긴
라멘 기억을 모은 `나의 라멘 지도`가 만들어지는 방식이다.

이 아이디어는 태그 기능이 없는 현재 랜딩에서 제공하거나 암시하지 않는다. 구현
전에는 태그 생성·선택·필터링이 실제 앱 기능으로 확정됐는지 먼저 확인한다.
